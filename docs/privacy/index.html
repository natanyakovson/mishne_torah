Политика конфиденциальности

Последнее обновление: 23 сентября 2026 г.

Приложение «Мишне Тора — Рамбам» уважает конфиденциальность пользователей.

Сбор данных

Приложение не требует регистрации или создания учетной записи и не собирает персональные данные пользователей.

Приложение не использует рекламные системы, системы отслеживания пользователей или аналитические сервисы.

Закладки, настройки чтения и другие пользовательские настройки сохраняются локально на устройстве пользователя и не передаются разработчику.

Получение текстов

Приложение может подключаться к серверу для получения и обновления текстового содержимого «Мишне Тора». Это соединение используется для предоставления содержимого приложения и не используется разработчиком для создания профилей пользователей или отслеживания их активности.

Сторонние сервисы

Для доставки и обновления содержимого приложение использует инфраструктуру Supabase. Приложение не передает Supabase имя, адрес электронной почты, учетную запись или содержимое пользовательских закладок и настроек.

Дети

Приложение не предназначено для сбора персональных данных детей и не собирает персональные данные пользователей.

Изменения политики

Политика конфиденциальности может обновляться при изменении функциональности приложения. Актуальная версия всегда будет доступна на этой странице.
