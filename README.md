# Mishneh Torah Prototype

SwiftUI-прототип приложения для 14 книг «Мишне Тора» Рамбама.

## Цель первого этапа

- единая кодовая база для iPhone, iPad и Mac;
- локальная база данных через SwiftData;
- структура: книга -> раздел -> глава -> галаха;
- поиск по тексту;
- закладки;
- история чтения;
- настройка размера текста;
- светлая/тёмная/системная тема;
- офлайн-работа;
- импорт русского текста пользователем, с сохранением оригинального иврита.

## Важно про текст

В проект включён полный локальный корпус «Мишне Тора» на русском и иврите, скачанный с m770.org после того, как пользователь сообщил о полученном разрешении на использование текста в приложении.

Перед распространением приложения нужно сохранить атрибуцию источника m770.org и условия полученного разрешения.

## Как открыть

1. Откройте `MishnehTorahPrototype.xcodeproj` в Xcode 15+.
2. Выберите схему `MishnehTorahApp`.
3. Запустите на Mac, iPhone simulator или iPad simulator.

## Интерфейс

Текущий прототип оформлен в стиле текстовой библиотеки, вдохновлённой Sefaria: бумажный фон, зелёный акцент, тонкие разделители, компактная навигация по текстам и спокойный режим чтения. Логотипы и брендовые элементы Sefaria не используются.

## Архитектура

- `Models/` - SwiftData-модели: книги, разделы, главы, галахот, закладки, история, настройки.
- `Persistence/` - контейнер SwiftData, сидер демо-данных и будущий импорт.
- `Views/` - SwiftUI-экраны приложения.
- `Resources/seed_books.json` - структура 14 книг и демо-текст.

## Формат будущего импорта

Ожидаемый формат можно расширить от текущего `seed_books.json`:

```json
[
  {
    "order": 1,
    "titleHebrew": "ספר המדע",
    "titleRussian": "Книга знания",
    "sections": [
      {
        "order": 1,
        "titleHebrew": "הלכות יסודי התורה",
        "titleRussian": "Законы основ Торы",
        "chapters": [
          {
            "number": 1,
            "halakhot": [
              {
                "number": 1,
                "hebrewText": "...",
                "russianText": "..."
              }
            ]
          }
        ]
      }
    ]
  }
]
```

`russianText` необязателен технически, но для русскоязычного приложения именно он используется как основной слой чтения и поиска. Если `russianText` отсутствует, приложение покажет сообщение, что русский текст для этой галахи ещё не импортирован.
